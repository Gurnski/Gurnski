## Day to day

TypeScript end to end: React or Next.js in front, Node.js behind, PostgreSQL through Prisma, Stripe when money changes hands, Playwright and Vitest to keep it honest. Python for analysis and prototypes. Java when a project is already written in it.

I am most interested in product engineering, applied AI and software that has to survive contact with real users.
